# Power-BI-Sales-Returns-Analytics-Dashboard
An interactive Power BI report designed to analyze sales performance, customer conversion funnels, return patterns, and key drivers influencing business outcomes.
---

## 🚀 Key Features & Insights

* **Key Drivers & Influencers:** Identified core factors driving return flags across sales channels, product categories, and discounts using Power BI's AI Key Influencers visual.
* **Customer Journey Funnel:** Tracked conversion across funnel stages to isolate drop-off points in customer acquisition.
* **Sales & Returns Trend Analysis:** Evaluated volume trends (Units Sold vs. Count of Returns) across years and geographical regions using dual-axis combo charts.
* **Dynamic Interactivity:** Integrated cross-filtering, dynamic slicers, and drill-through pages for granular data exploration.

---

## 🛠️ Tech Stack & Skills Demonstrated

* **Business Intelligence:** Power BI Desktop (`.pbip` format)
* **Data Modeling & Calculations:** DAX (Measures, Calculated Columns, Time Intelligence)
* **Data Transformation:** Power Query / M
* **Core Analytics:** Funnel Analysis, Trend Analysis, Diagnostic Analytics
